# 目标仓位回测引擎（v0.1）

`src/core/target_position_backtest.py` 是一个纯计算模块：输入已冻结的
每日目标仓位与日线，输出逐笔虚拟成交、每日现金/持仓市值/NAV、标准
Sharpe 和最大回撤。它不调用 LLM，不读取或改变策略选择器、辩论模块或
行动决策层，也尚未接入主流水线或数据库。

## v0.1 冻结假设

- 信号在交易日 `t` 收盘后形成，只能在下一个上交所交易日 `t+1` 开盘成交。
- 买入成交价为开盘价乘以 `(1 + slippage_rate)`，卖出为开盘价乘以
  `(1 - slippage_rate)`；滑点率由调用方显式传入，待敏感性检验。
- 每笔交易分别记录佣金、卖出印花税、过户费；费率和最低佣金均由调用方显式传入。
- Sharpe 使用策略绝对净日收益减无风险日收益，而非相对基准收益；年化交易日数
  使用 242，属于待验证的 v0.1 年化假设。
- 无风险年利率没有默认值。每次实验必须显式记录数值、观测日期及来源。
- 买入持有基准复用同一成交、成本、滑点、整手和 NAV 计算路径。

## 真实数据接线前的硬前置条件

当前 DSA 的 A 股日线主路径请求的是前复权价格。前复权价格可用于连续的
价格收益观察，但历史价格不是严格的真实成交现金价格。`stock_daily` 也未保存
复权因子和公司行为事件。

因此，在补齐“不复权 OHLC + 显式现金分红/送配事件”的数据契约前：

- 不得把当前前复权数据接入此引擎作为真实账户回测；
- 若单独运行，只能标注为“复权价格收益模拟”；
- 不得对外声称其为精确现金/股数账本，也不得作为正式成本后评价结果。
